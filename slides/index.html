FRAMEWORKS ARE OPTIONAL06 / 14
LANGGRAPH WORKFLOW OR DEEP AGENT?

Same runtime family. Different autonomy.

Workflow for this first build

  • Route to SQL, docs, or both
  • Bounded read-only tools and query budget
  • Check citations, then answer

Deep Agent for analyst work

  • Plan an investigation as it learns
  • Work through large, variable evidence
  • Delegate domains; create a report

Deep Agents is a LangGraph-based harness—not a separate competing runtime. Keep warehouse access narrow in either design.
