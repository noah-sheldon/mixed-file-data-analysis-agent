FRAMEWORKS ARE OPTIONAL07 / 15
WORKFLOW OR DEEP AGENT?

Use an agent when the next step is unknown

Workflow · normal analyst question

  • Plan one route
  • Run scoped SQL/search
  • Check sources and answer

Deep Agent · open investigation

  • Inspect results and choose next action
  • Repeat within a tool/time budget
  • Write a report; request review

Deep Agents uses LangGraph underneath. It adds autonomy; it does not replace the data pipeline.
